# ivanloughman.com

Built by GitHub Pages with Jekyll — no build step needed.

## Posting a thought

1. Create `_posts/YYYY-MM-DD-short-title.md` (on GitHub: **Add file → Create new file**).
2. Start it with:

   ```markdown
   ---
   title: Your title here
   ---

   Write in Markdown below.
   ```

3. Commit to `main`. It shows up on the home page within a minute or two.

Unfinished ideas can live in `_drafts/` (no date in the filename); they aren't published.
